# МЭШ — автозаполнение Soft Skills

Выставляет оценку учебных умений (soft skills) всем вашим ученикам в МЭШ по их среднему баллу за текущий период.
Ничего вводить не нужно: учитель, учебный год, период soft skills и ваши классы определяются автоматически.

## Установка расширения (Chrome, Яндекс.Браузер, Edge)

1. Скачайте архив **[mesh-soft-skills-extension.zip](./mesh-soft-skills-extension.zip)** и распакуйте его в любую папку.
2. Откройте страницу расширений: `chrome://extensions` (в Яндекс.Браузере — `browser://extensions`, в Edge — `edge://extensions`).
3. Включите **«Режим разработчика»** (переключатель справа вверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную папку.

Tampermonkey не нужен. Если он у вас уже стоит, можно вместо расширения установить
[`mesh_soft_skills_autofill_pro.user.js`](./mesh_soft_skills_autofill_pro.user.js) — это тот же код.

## Как пользоваться

1. Войдите в МЭШ как учитель (school.mos.ru).
2. Нажмите синюю кнопку **«★ Soft Skills»** в левом нижнем углу (или значок расширения на панели браузера).
3. Панель сама найдёт ваши классы и покажет всех учеников с рассчитанными ответами.
   Нажмите на класс, чтобы увидеть список. Снимите галочку с класса, если его не нужно заполнять.
4. Нажмите **«Выставить soft skills»**.

Уже заполненные анкеты не трогаются. Чтобы перезаписать их, отметьте «Перезаписать уже заполненные анкеты».

## Как считаются ответы

- **Классы** берутся из вашего расписания на этот учебный год. Уроки, где вы кого-то заменяли, не учитываются.
- **Анкета одна на ученика** по всем вашим предметам (так устроено в МЭШ). Если ученик есть в двух ваших группах,
  средний балл считается по оценкам из обеих.
- **Средний балл** считается по вашим оценкам за текущий период soft skills (например, «1 УП» — 01.09–01.11) с учётом веса.
- Ответ на каждый вопрос: средний балл + поправка вопроса (выступления и интерес вне программы — чуть ниже,
  ДЗ и вежливость — чуть выше) + небольшая постоянная поправка для ученика, чтобы ответы не были одинаковыми.
  - «Почти всегда» — от 4.6 (самообразование — от 4.8)
  - «Часто» — от 3.7 (самообразование — от 4.0)
  - иначе «Редко»
- **«Почти никогда» не ставится.** Слабые ученики, в том числе те, у кого только двойки, оцениваются как троечники (как при среднем 3.3).
- Если у ученика нет оценок за период — «Затрудняюсь ответить».

## Консольная версия

[`mesh_soft_skills_autofill.py`](./mesh_soft_skills_autofill.py) делает то же самое из терминала (`pip install requests`):

```
python3 mesh_soft_skills_autofill.py                 # только показать, что будет выставлено
python3 mesh_soft_skills_autofill.py --apply         # выставить незаполненным
python3 mesh_soft_skills_autofill.py --apply --overwrite
```

Токен — значение cookie `aupd_token` с school.mos.ru (через `--token`, переменную `MESH_TOKEN` или файл `~/.mesh_token`).

## Для разработки

Исходник расширения — `extension/softskills.js`. После правок запустите `./build.sh`: он соберёт скрипт Tampermonkey и архив расширения.
